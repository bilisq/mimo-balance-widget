# v0.1.1 更新内容

本次更新做了两件事：**让透明区不再挡住其它程序**，以及**把"气泡关不掉"这类交互补齐**。

> 适用于 Windows 10 / 11。解压到**纯英文路径**，双击 `MiMoBalanceWidget.exe` 即可。

## 新增

### 透明区点击穿透

挂件窗口只有右下角一小块是宠物，其余是透明的。以前那块透明区域会挡住下面窗口的点击，
现在：

- 空白处点击**直接落到下面的程序**（浏览器、编辑器都能正常点）；
- 宠物本体、余额面板、设置菜单、诊断面板**照常可点**；
- 拖拽宠物时不会因为拖出宠物边界而丢事件。

实现方式：主进程默认 `setIgnoreMouseEvents(true, { forward: true })`，
渲染层按元素矩形做几何判定，光标进入可交互区域时切回捕获。

### 气泡与面板的关闭行为

- **余额面板**：打开后 **5 秒自动收起**；**点空白处立即关闭**；鼠标停在面板上时暂停计时，移开重新计时；
  切到别的程序也会关闭。
- **提示气泡**（余额 / 本轮消耗）：**5 秒自动消失**，点任意处或窗口失焦立即关闭。
- 「等待回答 / 等待授权」的气泡保持常驻，不会被误关。

## 修复

- **宠物点不动**：点击穿透上线后，渲染层调用了一个并不存在的窗口接口，
  异常被静默吞掉，导致窗口永远停在"忽略鼠标"状态——空白能穿透，宠物却点不到。
- **「检查更新」按钮从 0.1.0 起就是坏的**：菜单调用了渲染层没有暴露的方法，
  点它只会报错。现在可以正常工作（点击后才请求 GitHub，平时不联网）。

## 升级方式

0.1.0 与 0.1.1 的配置和数据格式**完全兼容**，直接覆盖安装目录即可：

1. 关掉正在运行的挂件（托盘图标 → 退出）；
2. 用新包解压覆盖原目录（或解压到新目录后再删旧的）；
3. 双击 `MiMoBalanceWidget.exe`。

Cookie、缩放、主题、皮肤、开机自启、位置记忆都会保留。
如果换了目录，**建议在挂件目录里跑一次 `setup.cmd`**，让开机自启和命令行入口指向新位置。

## 注意

- **安装路径不能含中文**：实测中文目录下 Electron 起不来（进程直接退出、连日志都不写）。
  如果双击没反应，先检查路径。
- **exe 未签名**：首次运行可能出现在 SmartScreen 提示，点「更多信息 → 仍要运行」。
- 数据来自 MiMo 控制台**非官方**接口，需要自备 Cookie；接口变更时余额会提示失效而不是显示 0。
- 账本里的"今日/7 天消耗"是按余额差值**估算**的（界面标了 `≈`），退款、赠金到账/过期都会算进去。
